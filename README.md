# 第二单 SecondOrder

> 贵州白酒出海的首单决策副驾。
> 把一张展会名片，变成一份可执行的首单决策简报。

**赛道**：传统行业 AI 解决方案 · **方向**：AI × 白酒（营销与经销商运营 Agent）
**具体岗位**：贵州仁怀／遵义中小酒企的外贸专员

---

## 我们锁定的那个堵点

不是「白酒怎么出海」，是**一家没有海外团队的中小酒企，怎么让第一个海外经销商下第二单**。

遵义综合保税区 2025 年的工作总结给了一组罕见的诚实数字：

```
89 家完成出口资质备案
 ↓
35 家有出口意向
 ↓
11 家首次通过综保区出海
 ↓
 5 家与东南亚经销商「建立初步联系」        转化率 5.6%
```

注意最后一级的措辞——是「建立初步联系」，不是签约，更不是复购。公开资料在这里就断了。

遵义自己列出的第一个障碍是：**「找客户困难——白酒属管制商品，进口方需酒牌资质」**。
你的潜在客户不是「想卖酒的人」，是「已经持牌的人」。这个池子在任何国家都有限、封闭、且早被洋酒喂饱。

而中国的税制让事情更复杂：白酒出口**免征消费税**（20% 从价 ＋ 0.5 元／500ml 从量）、**退增值税 13%**。
这个税差本身就有人要——与酒卖不卖得掉无关。业内的描述是：「有些货根本没出境，在自贸区转一圈就回来了。」

所以外贸专员真正的问题有三个，而市面上的工具一个都没答：

1. 这个买家是真的想卖酒，还是在做税差？
2. 这瓶酒到他的货架上要卖多少钱？卖得动吗？
3. 第一份合同该写死哪几条，才能让他有动机下第二单？

## 这个原型做什么

一条主链路，六步跑完：

| 步骤 | 做什么 | 谁在做 |
|---|---|---|
| 1 | 粘贴展会名片／微信对话／邮件 | 人 |
| 2 | 抽取买家身分、诉求、关键引述 | 大模型 |
| 3 | 六项信号初判 → 套利风险评分 | 大模型初判 + 规则计分 + **人工覆核** |
| 4 | 目的国持牌核查：买方要什么、你要什么、缺了会怎样 | 规则库 |
| 5 | 落地价逐层推演 → 对标当地同价位烈酒 → 规格反推 | 规则库 |
| 6 | 卖点弹药：香型 × 料理 × 该市场已验证的白酒用法 | 知识库 |
| 7 | 首单发出之后的 90 天：七个节点，每个都连到一条合同条款 | 规则库 |
| 8 | 首单决策简报：这一单错了值多少钱／判定／必问清单／合同条款／第一封回信 | 规则库 + 大模型 |

输出的决策简报可一键复制成纯文字（约 1,200 字），直接贴进微信或邮件带去给老板看。

### 三件容易被忽略、但真的会出事的检查

**他打算怎么卖，决定了你算的价对不对。**
白酒在海外的主战场是餐饮，不是货架。同一瓶酒走餐饮渠道的终端价是走零售的三倍以上——
餐饮端毛利率 75–85%，零售只有 20–23%。工具里两套渠道可切换，三层加价率都能改，
依据是美国三层制的公开数据（进口商 50–55%、批发 20–40%、零售加价 25–30%、餐饮 75–85%）。

**你可能根本寄不出那两支样品。**
展会上最容易脱口而出的一句是「我寄两支给你试试」——而 53 度白酒在国际运输规则里是
第 3 类易燃液体。DHL、FedEx、UPS 一般不收，须走化工品专线，还要非危险品报告、
可运输证明、非危险品运输保函，收件方必须是持进口许可证的法人。
工具会依你选的酒自动判定，并把三条度数分界线画在一起：
**20 度是越南税率分界、24 度是危险品分界、70 度是禁运线。**

**第一单发出去之后的三个月，才是第二单的战场。**
这个工具叫「第二单」，所以功能不能停在报价与签约。
D+7 要落地仓照片（货停在保税仓是套利最明显的信号）、D+30 要终端陈列照片、
D+45 是补货窗口、D+90 是第二单决策点、D+180 独家条款失效。
每个节点都对应一条你上一步选的合同条款；买家风险高时，D+7 与 D+30 会被特别标出来。

### 最后给一个数字：这一单判断错了，代价是多少

其他功能都在讲「该检查什么」，没有一个在回答「为什么值得花这三分钟」。
决策简报开头直接用他刚填的报价乘出来：试销一单 13 万、整柜 261 万、
**一柜卖不掉折价倒回国内是 100 万的损失**——还没算价格体系被砸之后在那个市场的下一次机会。
美国市场会多一行：**没把 CBMA 额度指派给进口商，等于白送 12.8 万**，而这个动作不花一毛钱。

### 从真实品项出发，不是凭空填数字

工具内建 **56 支贵州白酒**的品项库（茅台系列、习酒、董酒、珍酒、国台、金沙回沙、鸭溪窖、贵州醇……），
资料含生产企业、产区带、香型、典型酒精度、酿造工艺与该酒自己的香气／口感描述。
选一支之后，**香型与酒精度会自动带进落地价测算与卖点弹药**。

这一步在 demo 里很有说服力：把 54 度的董酒换成 35 度的贵州醇，
新加坡的落地税负从 **69% 掉到 48%**，终端价少 160 元——因为新加坡是按纯酒精量课税的。
低度化不是抽象主张，是同一个产区里两支真实的酒之间，看得见的价差。

### 两个容易被忽略但重要的行为

- **规格反推**：选定市场后，系统会用同一套税则试算 53°／43°／38°／19°／小容量五种规格，
  告诉你「为了这个市场该出什么酒」。在越南，19 度版本的落地税负从 172% 降到 123%——
  因为 特别消费税 以 20 度为分界。低度化在这里不是口味问题，是财务问题。
- **卖点弹药**：买家问完价格，下一句一定是「这酒在我这里怎么卖」。
  系统给出香型对应的料理方向（酱香配熟成起司、浓香压川菜辣度、清香最接近伏特加）、
  一句话说法，以及该市场已经被记录下来的白酒用法（每条标注证据强度）。
  还有一件业务员上场前该知道的事：**非华人第一次闻到白酒，说的是「臭起司、八角、凤梨、麝香、汽油」**——
  所以第一次试酒不要单独纯饮。
- **规则库没涵盖的市场，会明讲**：贴一段日本买家的对话，系统不会默默套用默认市场，
  而是明确告诉你「这个买家看起来在日本，规则库只涵盖五个市场，下方测算不适用」。
  假装全知比诚实的边界危险得多。

## 现场能讲的三个「行家细节」

这三件事都写进了规则库，不是讲稿：

1. **香港减税只减「200 港元以上的那一段」**
   2024/10/16 起 >30% 酒精浓度的酒类，200 港元以上部分税率由 100% 降至 10%，以下维持 100%。
   结果：同一批酒，内销开票 320 元的版本落地税负 100%，开票 800 元的版本只有 40%。
   **想用低价光瓶酒打进香港，是税制上最贵的路。**

2. **新加坡按纯酒精量课税，所以「低度化」首先是一笔帐**
   S$88／公升纯酒精。53 度 500ml 一瓶含 0.265 公升纯酒精，光消费税就 S$23.32，与你的出厂价无关。
   在越南更极端：特别消费税 以 **20 度**为分界，20 度以上 65%，以下 35%——**一度之差，税率差近一半**。

3. **美国的 CBMA 额度必须由中国酒厂主动指派给进口商**
   联邦消费税标准 $13.50／标准酒精加仑（proof gallon），CBMA 优惠为前 10 万 标准酒精加仑（proof gallon） $2.70。
   2023 年起进口商须先全额缴给 CBP，再凭外国生产商指派的额度向 TTB 申请退税。
   不指派，进口商每瓶多付约 10.7 元人民币——**一个 20 尺柜就是十几万**，而这个动作不花你一毛钱。

## 技术路径：为什么这么做，为什么不那么做

```
名片／对话 → [大模型抽取] → [六信号初判] → [人工覆核]
                                              ↓
              [风险评分] ← [落地价计算] ← [持牌核查]      ← 全部是规则库
                    ↓
              [条款选取] → [大模型写回信] → 决策简报
```

- **税则、牌照、条款不交给模型。** 算错就是真金白银的亏损。全部是可审计的 TypeScript 纯函数，
  每一条都带 `source` 与 `asOf`，界面上鼠标移到 ⓘ 就能看到出处与版本。
- **模型只做两件它擅长的事**：把自然语言抽成结构、把结论写成人话。
- **六项信号的最终判定权在人手上。** AI 看得到文字，看不到展位上对方说「标签不用改」时的表情。
- **离线可跑完主链路。** 三个示范案例带本机预解析结果；落地价、牌照核查、合同条款全部本机计算。
  现场断网，这条主链路照样从头跑到尾（界面会标示已切换备用）。

## 那我直接问通用大模型不就好了？

可以问，而且会得到一个听起来很像样的答案。问题出在三个地方——而这三件事，
恰好就是外贸专员拿这个答案去跟老板报价时会出事的三个地方：

| | 通用模型 | 这个工具 |
|---|---|---|
| **细节** | 多半给你「约 30–50% 综合税负」的模糊区间 | 新加坡按纯酒精量、越南 20 度分界、美国 CBMA 指派——逐条查出来写进规则库 |
| **稳定性** | 同一题问两次，数字可能不一样 | 纯函数计算，同样输入永远同样输出，可逐行覆核 |
| **可追溯** | 不会告诉你出处与生效日期 | 每条税率标了 `source` 与 `asOf`，界面上 ⓘ 可查 |

换句话说：我们不是在跟通用模型比谁更会讲话，是把一个垂直领域的规则翻出来、写死、标上出处。
模型负责的是它真正擅长的两件事——把一段乱七八糟的微信对话读成结构，和把结论写成一封能寄出去的信。

## 已知边界

- 美国州级酒税未计入（各州差异极大）。
- 越南关税采最惠国 50%，ACFTA 优惠税率须逐案核定。
- 对标酒款为示意价，用于量级对照，非即时报价。
- 六项信号的权重目前是团队设定值，尚未用真实案例校准——这是上线前的第一件事。
- **产品形态还不对。** 外贸专员整天在微信里，不会为了判断一个买家去开网页。
  网页是 demo 的形态，真正会被用起来的是企业微信机器人——转发一段对话给它，回一份决策简报。
  这件事写进了赛后 100 天计划的第四步。
- 规则库目前涵盖五个市场（香港、新加坡、越南、美国、韩国）。日本原本在候选名单里，
  但公开资料对スピリッツ税率的表述不够明确，宁可不收——加一个市场的成本大约是一个人半天，
  因为税则本来就是公开的；收一条不确定的税率，代价是整个规则库的可信度。
