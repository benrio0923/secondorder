# 第二單 SecondOrder

> 貴州白酒出海的首單決策副駕。
> 把一張展會名片，變成一份可執行的首單決策簡報。

**賽道**：傳統行業 AI 解決方案 · **方向**：AI × 白酒（營銷與經銷商運營 Agent）
**具體崗位**：貴州仁懷／遵義中小酒企的外貿專員

---

## 我們鎖定的那個堵點

不是「白酒怎麼出海」，是**一家沒有海外團隊的中小酒企，怎麼讓第一個海外經銷商下第二單**。

遵義綜合保稅區 2025 年的工作總結給了一組罕見的誠實數字：

```
89 家完成出口資質備案
 ↓
35 家有出口意向
 ↓
11 家首次通過綜保區出海
 ↓
 5 家與東南亞經銷商「建立初步聯繫」        轉化率 5.6%
```

注意最後一級的措辭——是「建立初步聯繫」，不是簽約，更不是複購。公開資料在這裡就斷了。

遵義自己列出的第一個障礙是：**「找客戶困難——白酒屬管制商品，進口方需酒牌資質」**。
你的潛在客戶不是「想賣酒的人」，是「已經持牌的人」。這個池子在任何國家都有限、封閉、且早被洋酒餵飽。

而中國的稅制讓事情更複雜：白酒出口**免徵消費稅**（20% 從價 ＋ 0.5 元／500ml 從量）、**退增值稅 13%**。
這個稅差本身就有人要——與酒賣不賣得掉無關。業內的描述是：「有些貨根本沒出境，在自貿區轉一圈就回來了。」

所以外貿專員真正的問題有三個，而市面上的工具一個都沒答：

1. 這個買家是真的想賣酒，還是在做稅差？
2. 這瓶酒到他的貨架上要賣多少錢？賣得動嗎？
3. 第一份合同該寫死哪幾條，才能讓他有動機下第二單？

## 這個原型做什麼

一條主鏈路，六步跑完：

| 步驟 | 做什麼 | 誰在做 |
|---|---|---|
| 1 | 貼上展會名片／微信對話／郵件 | 人 |
| 2 | 抽取買家身分、訴求、關鍵引述 | LLM |
| 3 | 六項訊號初判 → 套利風險評分 | LLM 初判 + 規則計分 + **人工覆核** |
| 4 | 目的國持牌核查：買方要什麼、你要什麼、缺了會怎樣 | 規則庫 |
| 5 | 落地價逐層推演 → 對標當地同價位烈酒 → 規格反推 | 規則庫 |
| 6 | 首單決策簡報：判定／必問清單／合同條款／第一封回信 | 規則庫 + LLM |

輸出的決策簡報可一鍵複製成純文字（約 1,200 字），直接貼進微信或郵件帶去給老闆看。

### 兩個容易被忽略但重要的行為

- **規格反推**：選定市場後，系統會用同一套稅則試算 53°／43°／38°／19°／小容量五種規格，
  告訴你「為了這個市場該出什麼酒」。在越南，19 度版本的落地稅負從 172% 降到 123%——
  因為 SCT 以 20 度為分界。低度化在這裡不是口味問題，是財務問題。
- **規則庫沒涵蓋的市場，會明講**：貼一段日本買家的對話，系統不會默默套用預設市場，
  而是明確告訴你「這個買家看起來在日本，規則庫只涵蓋五個市場，下方測算不適用」。
  假裝全知比誠實的邊界危險得多。

### 三個真實感的示範案例

| 案例 | 市場 | 風險分 | 判定 |
|---|---|---|---|
| GoldenLink Trading（展會微信） | 新加坡 | **100** | 高度疑似套利型買家 |
| Pacific Rim Beverage（英文郵件） | 美國 | **36** | 需要進一步盡調 |
| An Phú Foods（展會後郵件） | 越南 | **0** | 偏向真實經銷需求 |

## 現場能講的三個「行家細節」

這三件事都寫進了規則庫，不是講稿：

1. **香港減稅只減「200 港元以上的那一段」**
   2024/10/16 起 >30% 酒精濃度的酒類，200 港元以上部分稅率由 100% 降至 10%，以下維持 100%。
   結果：同一批酒，內銷開票 320 元的版本落地稅負 100%，開票 800 元的版本只有 40%。
   **想用低價光瓶酒打進香港，是稅制上最貴的路。**

2. **新加坡按純酒精量課稅，所以「低度化」首先是一筆帳**
   S$88／公升純酒精。53 度 500ml 一瓶含 0.265 公升純酒精，光消費稅就 S$23.32，與你的出廠價無關。
   在越南更極端：SCT 以 **20 度**為分界，20 度以上 65%，以下 35%——**一度之差，稅率差近一半**。

3. **美國的 CBMA 額度必須由中國酒廠主動指派給進口商**
   聯邦消費稅標準 $13.50／proof gallon，CBMA 優惠為前 10 萬 proof gallon $2.70。
   2023 年起進口商須先全額繳給 CBP，再憑外國生產商指派的額度向 TTB 申請退稅。
   不指派，進口商每瓶多付約 10.7 元人民幣——**一個 20 尺櫃就是十幾萬**，而這個動作不花你一毛錢。

## 技術路徑：為什麼這麼做，為什麼不那麼做

```
名片／對話 → [LLM 抽取] → [六訊號初判] → [人工覆核]
                                              ↓
              [風險評分] ← [落地價計算] ← [持牌核查]      ← 全部是規則庫
                    ↓
              [條款選取] → [LLM 寫回信] → 決策簡報
```

- **稅則、牌照、條款不交給模型。** 算錯就是真金白銀的虧損。全部是可審計的 TypeScript 純函式，
  每一條都帶 `source` 與 `asOf`，介面上滑鼠移到 ⓘ 就能看到出處與版本。
- **模型只做兩件它擅長的事**：把自然語言抽成結構、把結論寫成人話。
- **六項訊號的最終判定權在人手上。** AI 看得到文字，看不到展位上對方說「標籤不用改」時的表情。
- **離線可跑完主鏈路。** 三個示範案例帶本機預解析結果；落地價、牌照核查、合同條款全部本機計算。
  現場斷網，這條主鏈路照樣從頭跑到尾（介面會標示已切換備援）。

## 那我直接問通用大模型不就好了？

可以問，而且會得到一個聽起來很像樣的答案。問題出在三個地方——而這三件事，
恰好就是外貿專員拿這個答案去跟老闆報價時會出事的三個地方：

| | 通用模型 | 這個工具 |
|---|---|---|
| **細節** | 多半給你「約 30–50% 綜合稅負」的模糊區間 | 新加坡按純酒精量、越南 20 度分界、美國 CBMA 指派——逐條查出來寫進規則庫 |
| **穩定性** | 同一題問兩次，數字可能不一樣 | 純函式計算，同樣輸入永遠同樣輸出，可逐行覆核 |
| **可追溯** | 不會告訴你出處與生效日期 | 每條稅率標了 `source` 與 `asOf`，介面上 ⓘ 可查 |

換句話說：我們不是在跟通用模型比誰更會講話，是把一個垂直領域的規則翻出來、寫死、標上出處。
模型負責的是它真正擅長的兩件事——把一段亂七八糟的微信對話讀成結構，和把結論寫成一封能寄出去的信。

## 跑起來

```bash
bun install
cp .env.example .env.local   # 填入 OPENAI_API_KEY / OPENAI_BASE_URL
bun run dev                  # http://localhost:3000
```

生產建置：

```bash
bun run build && bun run start
```

### 環境變數

| 變數 | 用途 | 備註 |
|---|---|---|
| `OPENAI_API_KEY` | 模型金鑰 | 缺少時自動走本機備援路徑 |
| `OPENAI_BASE_URL` | OpenAI 相容端點 | 預設 `https://api.openai-next.com/v1` |
| `N25_TEXT_MODEL` | 文字模型 | 預設 `gpt-5-mini` |

### 部署

Next.js 16 標準應用，可直接部署到 Vercel（`vercel deploy`）或任何支援 Node.js 的環境。
兩個 API route 為 `runtime = 'nodejs'`、`maxDuration = 60`。

```
src/
  lib/so/
    markets.ts     5 個市場的稅則、牌照、行家洞察、對標酒款（核心資產）

  components/so/   介面
  app/api/so/      extract（語意抽取）· brief（決策簡報）
```

## 資料來源

| 項目 | 來源 |
|---|---|
| 香港烈酒稅 | 香港特區政府新聞公報（2024-10-16 起生效） |
| 新加坡消費稅／GST | 新加坡海關 Duties and Dutiable Goods |
| 越南 SCT | 越南國會 2025-06-14 通過之特別消費稅法（含 2027–2031 逐年調升表） |

所有落地價為估算值，實際以海關核定為準；匯率為估算匯率。

## 已知邊界

- 美國州級酒稅未計入（各州差異極大）。
- 越南關稅採 MFN 50%，ACFTA 優惠稅率須逐案核定。
- 對標酒款為示意價，用於量級對照，非即時報價。
- 六項訊號的權重目前是團隊設定值，尚未用真實案例校準——這是上線前的第一件事。
- 規則庫目前涵蓋五個市場（香港、新加坡、越南、美國、韓國）。日本原本在候選名單裡，
  但公開資料對スピリッツ稅率的表述不夠明確，寧可不收——加一個市場的成本大約是一個人半天，
  因為稅則本來就是公開的；收一條不確定的稅率，代價是整個規則庫的可信度。
